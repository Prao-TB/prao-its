# Mazerunner

## Smeknamn

Mazerunner

## Tre saker jag vill lära mig

1. Hur man skapar flera nivåer.
2. Hur man justerar storleken på spelet.
3. Hur figuren reagerar när den träffar väggen eller kommer i mål.

## Hur spelet ska se ut

- Mörkt tema.
- Väggarna lyser rött.
- Figurerna är tydligt märkta med röd färg.
- Starten är grön och utgången är grön.
